# 프로테니스 · 랠리

테니스 레슨 예약 및 코치 주간 일정 관리 화면 시연입니다. 백엔드, 실제 예약, 결제, 알림, Google Sheets 쓰기 기능은 없습니다.

## 실행

- `dist/coach.html`: 코치 주간 레슨표 (2026년 11월 9–15일)
- `dist/index.html`: 레슨생 화면

파일을 브라우저에서 열거나 프로젝트 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000/dist/coach.html`에 접속하세요.

## 기능

코치 선택, 20분 단위 시간표, 레슨 등록, 예정 회차, 출석·불참, 예약 가능·불가 시간 설정, 브라우저 저장 및 초기화. 복잡한 기록은 원문 확인 대상으로 분리합니다. 출석은 예정 회차와 별개입니다.

## 데이터

Git에는 가상 시연 데이터 `dist/coach-data.sample.js`만 포함합니다. 실제 명단이 있는 `dist/coach-data.js`는 Git에서 제외되며 로컬에 존재할 때만 우선 사용합니다. 없으면 가상 데이터로 자동 실행됩니다. 실제 데이터를 공개 저장소에 추가하지 마세요.

## 검증

Node.js로 `node verify-coach.cjs`를 실행합니다. 데이터 보존, 주차, 회차, 상태 및 UI 이벤트 처리를 검사합니다. 브라우저 시각 검증을 대신하지는 않습니다.
