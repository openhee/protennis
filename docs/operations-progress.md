# 운영 전환 진행 상태

2026-11-14 기준. 취소/불참 자동 차감 규칙은 미확정.

1. 날짜 기반 캘린더: 주간 이동 구현, 기존 캘린더는 여전히 시연 저장 방식.
2. 실제 예약: /booking.html에서 코치 시간 개방/차단, 학생 즉시 확정 구현. 1:1만 지원.
3. 권한: 세션 검증 + private RPC 내부 계정/지점/역할/담당 코치 검사. 직접 테이블 쓰기 불가.
4. 중복: 코치 시간 겹침 DB 제약, 예약 대상/수강권 잠금, 회원 잠금, 요청 UUID 재사용 처리. 병렬 부하 테스트 추가 필요.
5. 출석/불참: 기존 시연만 존재. 실제 기록 연결 필요.
6. 수강권: 잔여 이관 및 예약 확보 구현. 실제 출석 차감/복구 연결 필요.
7. 취소/보강: 운영자 규칙 결정 필요.
8. 알림: 채널 및 발송 계정 결정 후 구현.
9. 관리자: 미구현.
10. 서울 이전: 운영 전 별도 이전 계획/실행 필요.

실제 코치 시간이 아직 등록되지 않아 예약 목록은 비어 있음. 테스트 예약은 트랜잭션 롤백으로 제거했고 잔여 4회 유지.
신희찬 수강권과 신홍경 코치 연결은 실DB에 등록됨. 연락처/결제/과거 출석은 임의로 생성하지 않음.
